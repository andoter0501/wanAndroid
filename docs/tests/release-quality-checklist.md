# 发布前质量检查清单

## 功能回归
- 首页：Banner、置顶、文章分页、鸿蒙专栏均可用。
- 发现：体系/导航/项目分类与分页可用。
- 搜索：热词、历史、结果分页可用。
- 登录：登录/注册/退出可用，登录失效会自动回到登录入口。
- 收藏：列表、取消收藏可用。
- 广场：列表、发布分享、删除分享可用。
- 问答：列表、评论查看可用。
- 消息：未读数、未读列表、已读列表可用。

## 稳定性
- 网络断开时页面有错误态与重试操作。
- `errorCode = -1001` 会自动清理会话并提示。
- 外链风险域名可被拦截并提示。

## 体验
- 关键页面均覆盖 Loading/Empty/Error 状态。
- 分页列表在无下一页时不再显示“加载更多”按钮。
- 主流程页面操作无明显卡顿与阻塞。
- 主要按钮点击区域可达、文案一致。
