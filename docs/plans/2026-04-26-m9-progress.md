# M9 交付记录（统一错误映射策略）

## 已完成
- 新增统一错误解析模块：
  - `common/network/ErrorMessage.ets`
  - 对 `SessionExpiredException`、`ApiException(401/403/404/429/5xx)`、网络异常进行统一文案映射。
- 移除各 ViewModel 内重复的 `parseError` 实现，全部改为调用 `parseErrorMessage`：
  - Home / Discover / Search / Auth / Collect / Plaza / Wenda / Message。

## 效果
- 错误文案一致，避免同类错误在不同页面出现不同提示。
- 业务层代码重复减少，后续只需在 `ErrorMessage` 一处维护错误策略。
