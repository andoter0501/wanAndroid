# M10 交付记录（统一页面头部组件）

## 已完成
- 新增通用页面头部组件：
  - `common/ui/components/PageHeader.ets`
  - 支持：标题、返回按钮、右侧动作按钮。

## 页面替换范围
- 首页：标题 + 搜索入口统一为 `PageHeader`。
- 发现：标题头统一为 `PageHeader`。
- 广场：标题头统一为 `PageHeader`。
- 问答：问答/评论两态标题统一为 `PageHeader`。
- 我的：标题头统一为 `PageHeader`。
- 搜索：返回 + 标题统一为 `PageHeader`。
- 网页详情：返回 + 标题统一为 `PageHeader`。

## 收益
- 头部样式和交互逻辑统一，避免页面各自实现导致的体验不一致。
- 后续新增页面可直接复用，减少重复代码和维护成本。
