# wanAndroid 鸿蒙客户端开发计划（执行版）

## 里程碑 M1：基础骨架（1-2 天）
- 建立工程模块目录与路由骨架。
- 完成 `network` 层：基础请求、响应解包、错误映射、Cookie 管理。
- 完成全局状态容器：登录态、网络态、主题态。

验收：
- 可请求任意公开接口并正确解析 `errorCode`。

## 里程碑 M2：首页与发现（2-3 天）
- 首页：Banner、置顶、文章列表、热门板块、鸿蒙专栏。
- 发现：体系/导航/项目三块能力打通。
- 完成通用 `ArticleCard`、`StateView` 组件。

验收：
- 首页与发现所有列表支持刷新与分页，异常态完整。

## 里程碑 M3：搜索与 Web 详情（1-2 天）
- 搜索热词、关键词检索、历史词管理。
- Web 详情页与外链跳转拦截策略。

验收：
- 关键词检索链路可用，翻页稳定。

## 里程碑 M4：账号与收藏体系（2-3 天）
- 登录/注册/退出、会话恢复。
- 收藏文章、收藏网站、编辑与删除。
- 处理 `-1001` 全链路。

验收：
- 登录后收藏状态跨页面一致，登出后状态正确清理。

## 里程碑 M5：广场、问答、个人中心、消息（2-3 天）
- 广场列表、我的分享、分享/删除。
- 问答列表与评论列表。
- 个人信息、积分、站内消息已读/未读。

验收：
- “浏览-登录-收藏-消息”主链路无阻塞问题。

## 里程碑 M6：测试与发布前加固（1-2 天）
- 单元测试：响应解析、分页逻辑、会话逻辑。
- UI/状态测试：加载、空态、失败、登录失效。
- 回归测试与性能检查。

验收：
- 核心流程回归通过，风险列表可追踪。

## 执行原则
- 按“纵向切片”开发：每次完成一条可演示用户流。
- 每个里程碑都保证可运行、可回归、可演示。
- UI 先保可用与一致，再做精修。
