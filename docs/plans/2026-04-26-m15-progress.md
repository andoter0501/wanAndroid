# M15 交付记录（收藏全链路联动）

## 已完成
- 新增全局收藏状态中心 `FavoriteService`：
  - 统一收藏/取消收藏请求入口
  - 缓存收藏状态
  - 事件订阅机制用于跨页面同步
- `ArticleCard` 增加收藏操作能力：
  - 支持展示收藏按钮
  - 支持收藏切换回调

## 页面接入范围
- 首页、搜索、广场、问答、分享人主页：
  - 全部接入收藏状态展示与切换。
- 我的收藏页：
  - 加载收藏列表时反向回填全局收藏状态
  - 取消收藏时同步更新全局状态
